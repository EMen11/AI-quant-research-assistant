# v1.0.0-demo

Proposed release note for the manually created `v1.0.0-demo` tag.

## Summary

AI Quant Research Workbench demonstrates a traceable research workflow in which deterministic
Python calculations, evidence identities and validation remain authoritative. Generated text is
treated as an untrusted proposal, and automated routing remains separate from explicit
`HumanReview`.

## Public demonstration

The [public Streamlit demo](https://ai-quant-research-assistant-2wpsobhnavfaznnp4pjmxt.streamlit.app/)
runs entirely offline from frozen, versioned fixtures. A public visit performs no provider
generation, market-data request, PostgreSQL connection or persisted review.

## Main features

- deterministic quant core with documented assumptions and frozen snapshot lineage;
- climate evidence with issuer, document, page, excerpt, source hash and provenance;
- evaluated BM25 and long-context retrieval baselines;
- structured LLM boundary with closed schemas and exact reference allowlists;
- deterministic validation and automated review routing separated from `HumanReview`;
- Streamlit analyst dashboard with admissible and blocked scenarios;
- local FastAPI, PostgreSQL and Docker Compose stack.

No automated status constitutes approval. A separate, explicit human decision is always required.

## Known limitations

The climate corpus covers two issuers, the retrieval gold set is small and the workflow holdout is
internal. Public results use frozen fixtures and apply only to the versioned cases and attack
families. Public reviews are unauthenticated and non-persistent; FastAPI, PostgreSQL and Docker are
local-only. Mobile verification used an emulated viewport, not a physical phone. Outputs are for
research and education, not investment advice.

## Quick start

```bash
git clone https://github.com/EMen11/AI-quant-research-assistant.git
cd AI-quant-research-assistant
uv sync --frozen --all-groups
APP_MODE=demo uv run --frozen streamlit run app.py
```

## Security and absence of live calls

Demo mode does not initialize the Anthropic adapter or the local API/database stack. It performs no
live provider generation during a public visit, stores no public reviewer identity and persists no
public review. The tracked-file secret scan is masked and intentionally narrower than a full Git
history or host-secret audit.
